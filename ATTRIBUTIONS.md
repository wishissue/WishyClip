## Design credit: WishIssue

The Wishy look is the work of **WishIssue** ([github.com/wishissue](https://github.com/wishissue)). Wishy Clip uses:

- the **Wishy Blue** palette (logo blue `#0166FF`, in light, dark, dusk and OLED variants), re-expressed as
  Wishy Clip theme tokens in `ui/design/themes/WishyBlue.kt`;
- the typography pairing of **Plus Jakarta Sans** for the interface.

## Icons

All UI icons use permissive open-source vector icon systems:

| Pack | License | Repository / License URL | Usage |
|---|---|---|---|
| **Material Symbols Rounded** | Apache 2.0 | https://fonts.google.com/icons , https://www.apache.org/licenses/LICENSE-2.0 | Every interface icon (outlined, plus filled for selected states). Local vector drawables generated by `tools/gen-symbols.mjs` from the `@material-symbols/svg-400` npm package (https://github.com/marella/material-symbols), which redistributes Google's Material Symbols. |

The previous Tabler Icons and Lucide icon sets are no longer used.

**Colour palette.** The Indigo theme family is generated by `tools/gen-themes.mjs` with `@material/material-color-utilities` (Apache 2.0). The hue relationship (indigo primary, lime accent, quiet neutrals) is a design reference to the Orion Store 2.x look; no Orion code, assets, logo or artwork is included, so Orion's GPL-3.0 does not apply to this project.
